# Deep-Sea Plastic Pulse

## The Coastal Sentinel Framework

**A Unified Global Framework for Satellite-Derived Weathering Detection, Bio-Ballistic Vertical Export Modelling, and Benthic Accumulation Forecasting**

**Target Journal:** Nature / Nature Geoscience  
**Institution:** Tianjin University  
**Author:** King Jones Adega  

---

## Overview

This repository contains the complete open-source implementation of the Coastal Sentinel framework, developed to resolve the 'missing plastic paradox' — the fact that over 99.7% of all plastic entering the ocean cannot be detected at the surface.

The framework makes three first-of-its-kind scientific contributions:

1. First satellite-based spectral classification of plastic Weathering State (W1-W4) at global scale
2. First empirical parameterisation of the Bio-Ballistic Density Function rho_p(t) validated against sediment trap records
3. First global 3D map of Vertical Export Corridors and Benthic Hotspots
