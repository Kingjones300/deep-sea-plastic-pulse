# Deep-Sea Plastic Pulse 
 
Code and figure generation scripts for the manuscript **Deep-Sea Plastic Pulse**. 
 
### Repository Structure 
- **scripts/main_figures/**: Python scripts for Main Text Figures 1-5 
- **scripts/extended_data/**: Python scripts for Extended Data Figures 1-4 
- **scripts/supplementary/**: Python scripts for Supplementary Figures 1-8 
- **outputs/**: Matched final manuscript figures (.png format)
